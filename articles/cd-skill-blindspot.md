## 「直った」と書かれている不具合を、直る前の版で踏んでみる

朝の確認スクリプトが「手元 2.1.304 / 最新 2.1.312」と出した。
毎朝これを1行で見るようにしたのは数日前で、さっそく仕事をしている。

最新の CHANGELOG を読んでいたら、こんな行があった。

> Fixed per-directory and `paths:` skills not being found after a Bash `cd` deeper into a git repository

ディレクトリごとに置いたスキルが、`cd` で深い階層に降りたあと見つからなくなる。それを直した、と書いてある。

実はこれ、同じ日の朝に踏んでいた。作業中にディレクトリが別のリポジトリへ飛んで、戻ってくるという動きがあった。
そのときは「そういうものか」で流したのだが、修正されたと書かれているのを見て、
**自分の環境では具体的に何が起きていたのか**を知らないままなのが気持ち悪くなった。
直ったと言われても、何が直ったのか分かっていないと、次に似たことが起きたときに気づけない。

なので、直る前の版（手元の 2.1.304）で再現させてみた。

## 作ったもの

使い捨てのリポジトリを1つ。

```
skilltest/
├── .claude/skills/roottest/SKILL.md     ← ルート直下
└── sub/deeper/
    └── .claude/skills/deeptest/SKILL.md ← 2階層下
```

中身はどちらも「呼ばれたら ROOTTEST-OK（DEEPTEST-OK）と出すだけ」のダミー。
`-p` で一発実行し、「`cd sub/deeper` してから、今使えるスキルの名前を全部出して」と頼む。

## 結果

| 条件 | `deeptest` は呼べたか |
|---|---|
| ルートで起動 → `cd sub/deeper` | 呼べない（0/3） |
| `sub/deeper` で起動（`cd` なし） | 呼べる（2/2） |
| `cd` 後に「探し直して」と明示的に頼む | 呼べない（0/2） |
| git 管理外・ルートで起動 → `cd` | 呼べない（0/1） |
| git 管理外・`sub/deeper` で起動 | 呼べる（1/1） |

1回あたり 10〜12 秒。

### 場所ではなく「どう来たか」で変わる

いちばん効いたのはここだった。

同じディレクトリ、同じファイル、同じ中身。違うのは**そこで起動したか、`cd` で降りてきたか**だけ。
ファイルの置き方でも、権限でも、フロントマターの書式でもない。経路だけ。

これは自分では絶対に疑わない種類の原因だと思う。
「読まれない」となったら普通はファイルを疑う。パスを確認して、書式を見直して、名前を変えてみる。
全部合っているので、さらに細かいところを見にいく。そして経路のことは最後まで思いつかない。

### 本人は「見えていない」ことを分かっている

`cd` したあとに「そこの `.claude/skills` を見て、今それが呼べる状態か答えて」と聞くと、こう返ってくる。

> `ls -a` の結果 `deeptest/` はあるが、自分の一覧には無いので呼べない

ファイルがあることは確認した上で、「でも使えない」と言う。
つまり**見えていないことは自覚できるが、自力では直せない**。起動し直すしかない。

報告としてはかなり親切な部類だと思う。黙って「そんなスキルはありません」で終わられるより、
「あるのは見えているが自分の手元には来ていない」と言ってくれた方が、原因の切り分けが一段進む。

### git は関係なかった

CHANGELOG は "deeper into a git repository" と書いているが、git 管理外のただのディレクトリでも同じように再現した。
条件は git かどうかではなく、`cd` の方だったと読める。

## 今日からできること

- ディレクトリごとのスキルを使うなら、**そのディレクトリで起動する**
- 「スキルが呼べない」と思ったら、書式やパスの前に**どこで起動したか**を思い出す

## 正直に書いておくこと

**最新の 2.1.312 で直っていることを、自分では確認していない。**
`npx` で 2.1.312 を実行して比較するつもりだったが、手元の実行環境の制限で通らなかった。
上の表は全部 2.1.304 の実測で、「2.1.312 では直っている」は CHANGELOG を信じているだけ。

あと測っていないこと。`paths:` 指定のスキルは手元に無いので試していない。
何階層降りると起きるのか（1階層でも起きるのか）も見ていない。

## おまけ

そのときに作った「毎朝バージョンを比べる1行」が、こうして今日のネタを拾ってきた。
思い出して確認する運用をやめて機械に見させた効果が、想定より早く出た。
