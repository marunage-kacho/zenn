## 回収率はKPIとして壊れている

ここまでの3章で見た通り、バックテストの回収率は嘘をつきます。しかも問題は検証バグだけではありません。仮に完璧にクリーンな検証でも、**回収率は分散が大きすぎて、現実的な標本数では何も教えてくれない**のです。

重賞は年に約130レース。1レースの配当は数百円から数万円まで裾の重い分布です。この条件で回収率は、大当たり1〜5レースで30〜60ポイント平気で動きます。「今年は回収率110%だった」は、エッジの証拠として統計的にほぼ無価値です。

では何を測ればいいのか。

## ブレンド率α — 「モデルは市場が知らないことを知っているか」

発想を変えます。モデルの予測確率と、オッズから逆算した市場の予測確率を混ぜた予測を考えます。

```
最終予測 = α × モデルの確率 + (1 − α) × 市場の確率
```

そして「実際の着順を最もよく説明するα」をデータから推定します（対数尤度の最大化）。このαが意味するものは明確です。

- **α = 0**: モデルを混ぜても予測は1ミリも良くならない。モデルの持つ情報は全て市場に織り込み済み
- **α = 1**: 市場は不要。モデル単独が最良
- **α = 0.2**: モデルには市場が知らない情報が少しあり、2割だけ混ぜる価値がある

回収率と違って、αは**全レース・全馬を使う**ので標本効率が桁違いに良く、配当の裾の重さにも影響されません。そして何より、**「儲かるか」の必要条件を直接測っています**。市場に織り込まれていない情報を持たないモデルは、控除率の分だけ構造的に負けるからです。

実装上の注意が2つあります。

1. **モデル出力の温度較正を先に行う**。機械学習モデルの出力確率はたいてい過信/過小気味で、そのままだとαの推定が歪む。温度パラメータTで較正してからαを推定する
2. **較正・推定は訓練期間外のデータで行う**。私は最初これを踏み外し、訓練期間と重なる期間で較正してα=0.09〜0.16という楽観値を出しました。訓練≦2023年・評価2024年に厳密分離すると0.000。**αの推定自体もリークするという教訓です**

## 事前登録して、変種を試す

α=0という結果に対し、「特徴量が足りないだけでは」という反論は当然ありえます。そこで改善仮説を**事前登録**して検証しました。試す変種を先に宣言し、後出しを封じます。

宣言した変種: ペース系（上がり3F相対値・位置取り変化）、トラックバイアス系、馬体重動態、乗り替わり、全部盛り、訓練データ1年分追加。

結果は全変種で **α = 0.000**。市場の非効率が残っていそうなニッチ（2歳新馬戦・ダート短距離・重不良馬場・少頭数）もセグメント別に測定しましたが、全て0でした。

| 変種 | α |
|---|---|
| ベース（147特徴量） | 0.000 |
| +ペース | 0.000 |
| +トラックバイアス | 0.000 |
| +馬体重動態 | 0.000 |
| +乗り替わり | 0.000 |
| +全部 | 0.000 |

前章の汚染修復後のクリーンデータでも再確認し、これが確定値になりました。**公開HTMLから作れる特徴量には、締切オッズ市場を上回る情報が存在しない。**

## このKPI設計の一般化

「モデルの絶対性能」ではなく「**強いベースラインに対する追加情報量**」を測る、という設計は市場系以外にも移植できます。

- 需要予測なら「先週同曜日と同じ」というナイーブ予測に対する改善分
- 検索・レコメンドなら人気順ベースラインに対する改善分
- 何かを予測するAI機能なら「その予測、既存の単純ルールに何%上乗せしてる?」

ベースラインが強い領域ほど、モデルの見かけの精度は「ベースラインの言い換え」で稼がれています。競馬の場合、市場という究極に強いベースラインがあり、モデルの「的中率30%」の中身は**9割以上がオッズの言い換え**でした。

では、その市場はどれくらい強いのか。次章で18万頭を使って実測します。
